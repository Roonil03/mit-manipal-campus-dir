# Annuaire du campus MIT Manipal

Annuaire destiné aux étudiants de MIT Manipal : restaurants, résidences, transport, services, ressources académiques, contacts de réclamation et numéros d’urgence.

## Exécution locale

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

Ouvrez `http://localhost:3000`. Modifiez `src/data/*.json` pour corriger les données ; consultez le [guide de contribution](CONTRIBUTING.fr.md) pour les détails.
