# Contribuer à l’annuaire MIT Manipal

Merci de contribuer à des informations de campus fiables, vérifiées et claires.

1. Forkez le dépôt et créez une branche de fonctionnalité.
2. Pour les données, modifiez le fichier JSON concerné dans `src/data/`.
3. Pour le code, exécutez `bun install` puis `bun dev`.
4. Avant une PR, exécutez `bun run lint`, `bun run check:styles`, `bun run typecheck` et `bun run build`.

N’ajoutez que des contacts officiels ou professionnels, vérifiez numéros et liens, et respectez les règles StyleX et TypeScript du projet.
