# एमआयटी मणिपाल निर्देशिकेत योगदान

कॅम्पसची माहिती अचूक, पडताळलेली आणि स्पष्ट ठेवण्यासाठी धन्यवाद.

1. रेपॉझिटरी फोर्क करा आणि फीचर शाखा तयार करा.
2. डेटा बदलांसाठी `src/data/` मधील योग्य JSON फाइल संपादित करा.
3. कोड बदलांसाठी `bun install` आणि `bun dev` चालवा.
4. PR आधी `bun run lint`, `bun run check:styles`, `bun run typecheck`, आणि `bun run build` चालवा.

फक्त अधिकृत किंवा व्यावसायिक संपर्क जोडा, प्रकाशित करण्यापूर्वी क्रमांक व दुवे पडताळा, आणि StyleX व TypeScript नियम पाळा.
