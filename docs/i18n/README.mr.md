# एमआयटी मणिपाल कॅम्पस निर्देशिका

एमआयटी मणिपाल विद्यार्थ्यांसाठी कॅम्पस निर्देशिका. रेस्टॉरंट्स, वसतिगृहे, प्रवास, सेवा, शैक्षणिक साधने, तक्रार संपर्क आणि आपत्कालीन क्रमांक येथे मिळतात.

## स्थानिकपणे चालवा

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

`http://localhost:3000` उघडा. माहिती दुरुस्तीसाठी `src/data/*.json` संपादित करा; अधिक तपशीलांसाठी [योगदान मार्गदर्शक](CONTRIBUTING.mr.md) पहा.
