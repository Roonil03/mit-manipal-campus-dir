# MITマニパル・キャンパスディレクトリ

MITマニパルの学生向けキャンパスディレクトリです。レストラン、寮、交通、サービス、学業リソース、苦情窓口、緊急連絡先を確認できます。

## ローカルでの実行

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

`http://localhost:3000` を開いてください。データを修正するには `src/data/*.json` を編集します。詳細は[貢献ガイド](CONTRIBUTING.ja.md)をご覧ください。
