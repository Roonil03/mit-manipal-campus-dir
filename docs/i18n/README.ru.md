# Справочник кампуса MIT Manipal

Справочник для студентов MIT Manipal: рестораны, общежития, транспорт, услуги, учебные ресурсы, контакты для жалоб и экстренные номера.

## Запуск локально

```bash
git clone https://github.com/aaditagrawal/campus-dir.git
cd campus-dir
bun install
bun dev
```

Откройте `http://localhost:3000`. Для исправления данных редактируйте `src/data/*.json`; подробности — в [руководстве по вкладу](CONTRIBUTING.ru.md).
