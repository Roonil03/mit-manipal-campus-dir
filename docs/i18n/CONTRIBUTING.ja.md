# MITマニパル・ディレクトリへの貢献

正確で検証済みのキャンパス情報を維持するご協力に感謝します。

1. リポジトリをフォークし、機能ブランチを作成します。
2. データ変更では `src/data/` の該当するJSONファイルを編集します。
3. コード変更では `bun install` と `bun dev` を実行します。
4. PR前に `bun run lint`、`bun run check:styles`、`bun run typecheck`、`bun run build` を実行します。

公式または事業者の連絡先のみを追加し、番号とリンクを確認し、プロジェクトのStyleXおよびTypeScript規約に従ってください。
