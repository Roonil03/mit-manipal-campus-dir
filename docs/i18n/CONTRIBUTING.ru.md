# Вклад в справочник MIT Manipal

Спасибо за помощь в поддержании точной и проверенной информации о кампусе.

1. Сделайте fork репозитория и создайте ветку функции.
2. Для данных измените подходящий JSON-файл в `src/data/`.
3. Для кода выполните `bun install` и `bun dev`.
4. Перед PR выполните `bun run lint`, `bun run check:styles`, `bun run typecheck` и `bun run build`.

Добавляйте только официальные или деловые контакты, проверяйте номера и ссылки и соблюдайте правила проекта для StyleX и TypeScript.
